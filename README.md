# PTCGL 検討（ホーム画面アプリ版）

iPhoneのホーム画面から全画面で起動する、自分用のバトルログ検討アプリです。
費用は0円。アプリはGitHub Pages（GitHubの無料公開機能）に置き、データとAPIキーはiPhoneの中に保存します。

## ファイル構成

```
index.html             … 画面
app.js                 … 画面の動きと処理の流れ
core.js                … ログの読み取り・事実の抜き出し・AIへの問い合わせ
manifest.webmanifest   … ホーム画面アプリとしての名前・アイコン・色
sw.js                  … オフラインでも画面が開けるようにする仕組み
icons/                 … アイコン画像（3サイズ）
```

---

## 1. GitHubに置く（10分ほど）

1. GitHubの右上「＋」→「**New repository**」
   - Repository name：`ptcgl-app`
   - **Public** を選ぶ（GitHub Pages を無料で使うために必要。中にAPIキーや対戦データは入らないので大丈夫です）
   - 「Create repository」
2. 「**uploading an existing file**」をクリック
3. 展開したフォルダの中身を**すべて**ドラッグ＆ドロップ
   （`index.html`、`app.js`、`core.js`、`manifest.webmanifest`、`sw.js`、`README.md`、そして `icons` フォルダごと）
4. 「**Commit changes**」
5. リポジトリの「**Settings**」→ 左メニュー「**Pages**」
   - Source：「**Deploy from a branch**」
   - Branch：「**main**」と「**/ (root)**」を選んで「**Save**」
6. 1〜2分待つと、同じ画面の上部に公開URLが表示されます
   `https://（あなたのGitHub名）.github.io/ptcgl-app/`

## 2. iPhoneのホーム画面に追加

1. iPhoneの **Safari** で、公開URLを開く
2. 共有ボタン →「**ホーム画面に追加**」
3. 名前が「PTCGL検討」、アイコンが表示されていることを確認して「**追加**」
4. 以後は**ホーム画面のアイコンから**開いてください（Safariの枠が消えた全画面で起動します）

> 前に作ったショートカットやStreamlit版のアイコンは、長押しで削除して大丈夫です。

## 3. 最初の設定

1. 起動すると「設定」画面が開くので、**Gemini APIキー**を貼り付け
2. **自分のプレイヤー名**（ログ上の表記。例：`S_Tobari`）を入力
3. 「デッキ」タブで、PTCGLからエクスポートしたデッキを登録

APIキーを入れると、裏で最新の環境の検索が自動で始まります（画面右上に「環境を更新中…」と出ます）。

### Streamlit版のデータを引き継ぐ場合（任意）
Streamlit版の「設定」→「バックアップを保存」で書き出したファイルを、
このアプリの「設定」→「バックアップを読み込む」で読み込めます。

## 使い方

**対局を検討する**
1. PTCGLの対戦終了画面 →「バトルログ」→ 全文コピー
2. 「検討」タブで「クリップボードから貼り付け」（または入力欄を長押し →ペースト）
3. 使ったデッキを選んで「この対局を検討する」

検討は、次の順番で行われ、進み具合が画面に表示されます。

| 手順 | 担当 | 内容 |
|---|---|---|
| ① ログの読み取り | アプリ | ターンごとに分ける |
| ② 事実の抜き出し | アプリ | サイド枚数・きぜつ・ワザ・使ったカード（正確） |
| ③ 環境の確認 | AI＋検索 | 環境メモが7日より古ければ先に検索して更新（裏で更新中ならそれを待つ） |
| ④ 盤面の再現と形勢の評価 | AI | 1ターンずつ「盤面を再現 → 評価 → より良い手」の順に考える |
| ⑤ 事実との照合と保存 | アプリ | ②の事実と食い違うところを直してiPhoneに保存 |

**履歴**：検討した対局は自動で貯まり、勝率と相手デッキ別の成績が見られます。
**デッキ**：一度登録すれば、毎回選ぶだけ。戦い方の解説も出せます。
**環境**：最新の環境メモ（参照ページつき）と、環境を踏まえたアドバイス。

## アイコンを自分の画像に変える

`icons` フォルダの3つの画像を、**同じ名前・同じ大きさ**の自分の画像に差し替えてGitHubにアップロードします。

| ファイル名 | 大きさ | 使われる場所 |
|---|---|---|
| `apple-touch-icon.png` | 180×180 | iPhoneのホーム画面 |
| `icon-192.png` | 192×192 | ブラウザのタブなど |
| `icon-512.png` | 512×512 | 起動画面など |

差し替えたら、ホーム画面のアイコンを一度削除して、もう一度「ホーム画面に追加」してください
（iPhoneは追加した時点のアイコンを覚えるため）。

> リポジトリは公開なので、置いた画像は誰でも見られます。ネットで拾った画像は権利に注意してください。

## アプリを更新する

変更されたファイルをGitHubに上書きアップロードするだけです。
次にアプリを開いたときに新しい版が読み込まれます（反映されないときは、一度アプリを閉じて開き直す）。

## 知っておいてほしいこと

- **データはiPhoneの中**にあります。PCで開くとPC側は別のデータです。機種変更に備えて、ときどき「設定」→「バックアップを書き出す」で保存してください（APIキーはバックアップに含まれません）。
- **APIキーもiPhoneの中**だけに保存され、Googleへの問い合わせにだけ使われます。
- Geminiの無料枠には1分あたり・1日あたりの回数制限があります。混雑や上限エラーのときは、自動で他のモデルに切り替えます。

## 困ったとき

| 症状 | 対処 |
|---|---|
| URLを開くと 404 | Pages の設定から1〜2分待つ。`index.html` がリポジトリの一番上にあるか確認 |
| 「APIキーが使えませんでした」 | 「設定」のキーを貼り直す |
| 「無料枠の利用上限」 | 1分待つ／翌日に再実行／「設定」でモデルを `gemini-3.5-flash-lite` に |
| 環境が古いまま | 「環境」タブの「最新の環境を調べる」。「検索結果を得られなかった」と出る場合は時間をおいて再実行 |
| 画面が更新されない | アプリを上にスワイプして閉じ、開き直す |
